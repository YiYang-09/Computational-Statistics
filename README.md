# Computational Statistics — Labs

Laborations for **732A89 Computational Statistics** at Linköping University, in **R**.

| Lab | Topics |
|---|---|
| [lab1](lab1) | Numerical maximization; computer arithmetic and the accuracy of variance estimators |
| [lab2](lab2) | Optimization: Newton's method (gradient + Hessian) and quasi-Newton **BFGS** |
| [lab3](lab3) | Random variate generation: inverse-CDF and rejection sampling, Box-Muller vs. `rmvnorm` |
| [lab4](lab4) | **Metropolis-Hastings**: normal vs. chi-square proposals and acceptance rates |
| [lab5](lab5) | **Bootstrap** for regression; simulation of power curves (sign test on Gumbel samples) |
| [lab6](lab6) | **EM algorithm** for mixture models; simulated annealing |

## Tooling

Base R, `ggplot2`, `mvtnorm`, `boot`

## Running

Open `Computational-Statistics.Rproj` in RStudio and knit the `.Rmd` files (data files are included in each lab folder).
